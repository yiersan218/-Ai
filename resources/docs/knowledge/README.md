# 知源 AI：华为商城 Agentic RAG 导购知识库（KBpro）

本知识库面向华为商城硬件导购，覆盖商品家族识别、稳定卖点、鸿蒙生态兼容、使用与选购、配送安装、退换货退款、保修维修和发票知识。

## 产品范围

- 手机、平板、笔记本、穿戴、耳机；
- 智慧屏、路由、音箱、智能眼镜；
- 打印机、智能门锁、家庭存储；
- 充电器、移动电源、数据线、手写笔、表带、保护壳和无线充电设备等主要配件。

不包含鸿蒙智行汽车、第三方鸿蒙智选商品、食品酒饮、数字内容和服务类商品。

## 数据边界

- KB：产品家族定位、稳定参数与卖点、兼容规则、选购方法、安装及服务政策。
- MCP：商品页查找、当前公开价格与在售线索、优惠、分期和以旧换新页面。
- 真实库存、结算价、个人订单、物流、账号、支付和售后工单不在当前工具能力范围内。
- 静态文档不得以采集时刻的价格、库存或“在售核验”作为当前事实。
