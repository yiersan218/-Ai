# 知源 AI：华为商城 Agentic RAG 导购知识库（KBpro）

本知识库面向华为商城硬件导购，覆盖商品家族识别、稳定卖点解释、鸿蒙生态兼容、使用与选购指南、配送安装、退换货、保修、发票和售后知识。

## 产品范围

- 手机、平板、笔记本
- 穿戴、耳机
- 智慧屏、路由、音箱、智能眼镜
- 打印机、智能门锁、家庭存储
- 主要配件：充电器、移动电源、数据线、手写笔、表带、保护壳和无线充电设备等

不包含鸿蒙智行汽车、第三方鸿蒙智选商品、食品酒饮、数字内容和服务类商品。

## 数据分工

- KB：产品家族定位、稳定卖点、兼容规则、选购方法、安装与服务知识。
- MCP：prdId、sbomCode、具体规格、价格、库存、优惠、配送地区、安装权益和当前可售 SKU。
- Prompt 与意图树：决定使用 KB、MCP 或混合查询，并控制追问和回答边界。

## 导入目录

六个编号目录分别对应意图树中的六个 KB 节点。完整文档清单见 `_meta/manifest.json`，产品目录见 `_meta/product-catalog.csv`，统计口径见 `_meta/statistics.md`，质量检查见 `_meta/validation.json`。
