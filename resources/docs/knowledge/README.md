## 数据边界

- 新增范围只包含有明确价格且未标记“暂时缺货”的华为主商品。
- 排除第三方配件、服务商品、华为智选、官方翻新和无报价占位商品。
- 价格、库存、优惠、分期、赠品和以旧换新资格由 MCP 实时查询，不写入 KB。
- 同一传播名存在多个 SKU 时，知识库保存稳定参数；具体颜色、存储、网络版本和套装需继续确认。
