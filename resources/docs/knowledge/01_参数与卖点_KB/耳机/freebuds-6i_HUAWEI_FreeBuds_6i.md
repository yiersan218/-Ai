# HUAWEI FreeBuds 6i 产品档案

## 商品定位

- 类型：入耳式降噪耳机
- 建议人群：通勤降噪、低音和性价比导向用户。

## 商城稳定卖点

- 旗舰级降噪深度
- 智慧动态降噪 3.0
- 低音澎湃

## 搭配与使用提示

这是蓝牙音频设备，可面向具备兼容蓝牙协议的手机、平板和电脑进行配对。基础音频、高清编码、空间音频、弹窗、查找、智慧助手和多设备连接的可用范围不同，必须按耳机型号、终端型号、系统和智慧生活应用版本核验。

- 与华为手机、平板或鸿蒙电脑搭配时，部分弹窗、高清音频、AI、空间音频或跨设备能力可能更完整，但需要满足具体机型和版本条件。
- 与 Windows、Android、iOS 等设备搭配时，先确认蓝牙基础连接，再单独确认降噪控制、高清编码、双设备连接和固件升级入口。
- “支持连接多个平台”不等于“支持同时连接两台设备”；多设备能力必须查询型号支持列表。

## 导购建议

先询问佩戴形态、降噪需求、运动场景、主要终端和是否需要多设备切换，再推荐型号。开放式产品更便于感知环境声，但不等同于主动降噪；入耳式产品的舒适度和降噪效果存在个体差异。
