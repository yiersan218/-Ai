# 寄修与维修前准备清单

## 办理前核对

1. 备份并移除不必要的个人数据
2. 记录设备序列号和外观状态
3. 准备有效购机与保修凭证
4. 选择预约、到店、寄修或支持的上门服务
5. 维修价格、备件和进度通过官方服务渠道查询

## 使用说明

本清单用于导购助手快速收集信息。具体资格、时限、区域和费用以对应官方政策页面及订单页面为准。

本条目仅描述当前知识库范围内的信息；具体型号、系统版本及功能支持情况以来源页面最新说明为准。
