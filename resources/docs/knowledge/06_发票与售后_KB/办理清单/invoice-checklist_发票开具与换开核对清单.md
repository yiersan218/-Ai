# 发票开具与换开核对清单

## 办理前核对

1. 下单时确认电子发票或专用发票类型
2. 核对个人或企业抬头及税务信息
3. 发票金额按实际支付规则生成
4. 在订单页面查询和下载电子发票
5. 需要换开发票时核对订单签收时间与官方期限

## 使用说明

本清单用于导购助手快速收集信息。具体资格、时限、区域和费用以对应官方政策页面及订单页面为准。
