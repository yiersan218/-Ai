# 华为商城发票修改与换开规则

## 先确认订单阶段

发票信息能否直接修改，关键取决于订单是否已经出库。

| 订单阶段 | 处理方式 |
|---|---|
| 未支付或已支付但尚未出库 | 可从订单的“修改订单”入口修改发票抬头或发票类型 |
| 出库中或已经出库 | 不能直接修改订单发票信息 |
| 已签收且在 180 天内 | 可按订单页面提供的入口申请自助换开发票 |
| 超过签收 180 天，或已经自助换票一次 | 联系华为商城客服，由客服核实是否能够继续处理 |

## 出库前修改路径

### APP

“我的” → “全部订单” → “修改订单” → 点击发票旁的更多入口 → “修改发票信息” → 确认并保存。

### PC

“我的订单” → “修改订单” → “发票信息修改” → 确认修改。

订单页面显示的实际按钮可能随版本变化；只要尚未出库，无论订单未支付还是已经支付，均应优先从订单详情尝试修改。

## 签收后的自助换开路径

### APP/WAP

“我的” → “我的订单” → “订单中心” → “已完成” → “查看发票” → 发票详情右上角“换开发票”。

### PC

“我的订单” → “已完成” → “订单详情” → “发票信息” → “换开发票”。

如电子发票换开增值税专用发票的自助申请失败，应联系人工客服处理，不要反复提交或承诺一定能够换开。

## 开票信息核对

1. 华为商城自营商品默认开具电子发票，也可在订单支持时选择专用发票。
2. 第三方代销商品支持的发票类型由对应第三方商家决定。
3. 企业抬头应与税务登记的单位名称保持一致，并准确填写纳税人识别号等页面要求的信息。
4. 发票内容按实际购买商品明细开具。
5. 发票金额按订单实际支付规则生成，优惠券、礼品卡、积分等非现金抵扣部分的展示以订单和发票票面为准。

## 开具时间

- 自营商品电子发票：订单完成后通常 24 小时内生成，可在订单页面下载。
- 专用发票：通常在签收后 8 至 10 个工作日开具并寄出，一般在订单完成后 15 个工作日内送达；节假日可能延迟。

一张订单原则上对应一张发票；因开票限制无法合并在一张票上时，系统可能自动拆分为多张，以实际收到的发票为准。

## 发票遗失或损毁

官方发票说明提示，应妥善保存发票；因个人操作造成纸质发票遗失或损毁时，商城可能无法提供更换或重开。发票遗失后的保修凭证判断与“重新开票”是两个问题：设备售后可进一步核对电子三包凭证、签收记录等材料，但这不等于原发票一定可以补开。

## 回答边界

- 180 天按订单签收时间核对，不能按下单时间推算。
- 自助换票入口、可换开的发票类型和所需税务信息，以订单页面为准。
- 超期、重复换票、第三方商品或电子票转专票失败时，应引导联系商城客服核实，不能保证处理结果。
