# 配送查询所需信息清单

## 办理前核对

1. 订单号和下单时间
2. 配送方式：商城配送、门店闪送或预约配送
3. 商品页面显示的预计发货时间
4. 收货地区及物流单号
5. 预售、定制或第三方发货标识

## 使用说明

本清单用于导购助手快速收集信息。具体资格、时限、区域和费用以对应官方政策页面及订单页面为准。

本条目仅描述当前知识库范围内的信息；具体型号、系统版本及功能支持情况以来源页面最新说明为准。
