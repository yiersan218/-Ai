# 打印机配送安装与验收清单

## 下单前

- 确认摆放空间、电源和网络
- 按说明移除运输保护并安装耗材
- 安装官方客户端或驱动并完成配网
- 打印测试页，核对扫描和移动打印能力

## 动态信息

配送范围、预约时间、安装费用、免费权益、特殊材料费和地区限制应由 MCP 或官方服务页面实时查询。知识库只提供准备和核对方法。

## 验收原则

确认外观、附件、序列信息、基础功能、网络或接口连接以及安装结果；异常应保留包装、照片、订单和服务单信息，并及时联系官方渠道。
