# 主要配件场景化选购指南

## 先问需求，再给型号

1. 目标设备的准确型号
2. 接口和协议
3. 所需功率或尺寸
4. 是否需要套装
5. 便携、耐用和安装方式

## 推荐流程

1. 用场景和硬约束筛掉不合适的产品家族。
2. 从产品目录中保留二至四个候选，并解释差异来自哪里。
3. 对接口、安装、系统和跨设备能力执行兼容检查。
4. 调用 MCP 获取候选的当前规格、SKU、价格、库存、促销和服务权益。
5. 给出主推荐、备选和不推荐原因，提醒用户最终核对所选 SKU。

## 常见误区

- 只比较宣传名，不确认具体配置。
- 将最高能力当成所有终端和所有场景都支持。
- 忽略安装环境、网络、接口、功率、尺寸或耗材。
- 用静态文档回答实时价格、库存和活动。

## 输出建议

答案应包含：用户需求复述、候选家族、关键取舍、兼容与安装风险、需要 MCP 实时确认的字段，以及下一步可执行动作。
