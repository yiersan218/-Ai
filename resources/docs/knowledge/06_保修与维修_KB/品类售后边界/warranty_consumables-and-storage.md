# 打印耗材、配件与家庭存储售后边界

- 耗材、镜片、保护壳、表带和定制类配件需确认拆封、使用后的退换限制。
- 家庭存储送修前应自行备份重要数据，维修不等于数据恢复承诺。
- 误购型号或接口不匹配时，保留完整包装并尽快按订单政策申请。
- 具体保修期、服务方式和备件价格由官方政策或 MCP 实时查询。

## 回答要求

不得仅凭本文件承诺退换或保修结果。必须结合购买渠道、订单时间、商品状态、故障现象和当前政策判断，并引导用户通过官方订单或服务渠道确认。
