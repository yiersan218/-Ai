# 电子三包凭证说明

## 适用说明

以下内容由华为官方页面规范化整理。涉及支持机型、系统版本和服务区域时，应以来源页面当前版本为准。

## 官方内容

手机、平板、笔记本电子三包凭证说明
适用产品： 手机，平板，笔记本

电子三包凭证是电子形式的保修凭证，部分产品支持以联网使用日期作为保修起始日期（由于信息更新需要一段时间，建议联网使用3-5天后查询），如您对查询的产品权益有疑问，可凭有效购机凭证（纸质发票/电子发票/签收记录）前往华为客服中心或拨打华为终端客服热线950800咨询。

线上购买参与国家以旧换新补贴的本产品，保修起始日期默认为签收次日（由于信息更新需要一段时间，建议签收3-5天后查询），如在签收次日前联网使用，则以设备联网使用日期作为保修起始日期（由于信息更新需要一段时间，建议联网使用3-5天后查询）。
