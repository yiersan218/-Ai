# 退换货申请办理清单

## 办理前核对

1. 从签收次日零时起核对申请期限
2. 先在我的订单页面提交申请
3. 根据原因准备商品、完整配件、包装和凭证
4. 质量问题按要求完成检测
5. 审核通过后按页面地址和方式寄回

## 使用说明

本清单用于导购助手快速收集信息。具体资格、时限、区域和费用以对应官方政策页面及订单页面为准。

本条目仅描述第一版知识库范围内的信息；具体型号、系统版本及功能支持情况以来源页面最新说明为准。
