# 保修与送修凭证清单

## 办理前核对

1. 设备准确型号和序列号
2. 纸质或电子发票、签收记录或电子三包凭证
3. 故障现象、发生时间与复现步骤
4. 送修前完成个人数据备份
5. 最终是否保修以授权服务中心检测为准

## 使用说明

本清单用于导购助手快速收集信息。具体资格、时限、区域和费用以对应官方政策页面及订单页面为准。

本条目仅描述第一版知识库范围内的信息；具体型号、系统版本及功能支持情况以来源页面最新说明为准。
