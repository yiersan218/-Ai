# 智慧屏与智能门锁安装类商品售后边界

- 安装前核对门体、墙体、尺寸和服务范围，避免因环境不符产生额外处理。
- 安装、激活、打孔或定制后可能影响无理由退货条件，应以订单和政策实时说明为准。
- 保留订单、SN、安装服务单、故障照片或视频。
- 安全类设备出现异常时先启用机械钥匙或应急方案，再联系官方服务。

## 回答要求

不得仅凭本文件承诺退换或保修结果。必须结合购买渠道、订单时间、商品状态、故障现象和当前政策判断，并引导用户通过官方订单或服务渠道确认。
