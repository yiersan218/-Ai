# 手机平板电脑穿戴耳机兼容关系矩阵

| 设备组合 | 主要连接方式 | 典型能力 | 必须核对 |
|---|---|---|---|
| 手机—平板 | 超级终端、多屏协同、华为分享 | 文件拖拽、跨设备操作、通信共享等 | 型号、系统版本、帐号与开关 |
| 手机—笔记本 | 多屏协同、华为分享 | 电脑操作手机、文件互传 | 电脑管家版本、型号与系统 |
| 平板—笔记本 | 多屏协同 | 镜像、扩展、协同输入与文件处理 | 电脑管家版本及支持清单 |
| 手机—穿戴 | 华为运动健康应用、蓝牙 | 绑定、通知、运动健康数据 | 手机系统、应用版本、帐号 |
| 手机/平板/电脑—耳机 | 蓝牙、智慧音频应用 | 音频、设备切换、多设备连接 | 耳机型号、系统和功能支持清单 |

矩阵只描述判断入口。具体设备是否支持某项能力，应检索对应官方清单文档。
