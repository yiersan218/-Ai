# 退款方式和周期

## 适用说明

以下内容由华为官方页面规范化整理。涉及支持机型、系统版本和服务区域时，应以来源页面当前版本为准。

## 官方内容

首页 > 帮助中心 > 退款方式和周期
退款方式和周期


## 一、商品退款方式


商城会将款项按照原支付方式退回。

注：因退货引起的退款，优惠券、花瓣将不予退回。


## 二、商品退款周期


申请退款后经工作人员确认审核通过，仓库在接收到客户退货的商品、发票原件、保修卡、检测报告、附件、赠品齐全，并且检验符合退换货标准后，商城将会在3-5个工作日内直接将款项退回您原支付账户，但具体的到账时间还取决于第三方支付或对应银行的到账时间。
