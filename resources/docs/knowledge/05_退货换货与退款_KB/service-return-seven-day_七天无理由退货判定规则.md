# 七天无理由退货判定规则

## 无理由退货与质量问题退货不是一回事

- 七天无理由退货：商品没有质量问题，用户在法定期限内改变购买决定，需要满足适用商品范围和商品完好要求。
- 质量问题退货：商品出现非人为性能故障，需要按商城或售后要求检测，适用三包及对应产品政策。

回答时应先确认用户属于哪一种原因，不能要求无理由退货用户提供质量检测报告，也不能把质量问题简单归为无理由退货。

## 时间如何计算

华为商城退换货政策按签收次日零时开始计算。申请是否在期限内，以用户在“我的订单”成功提交退换货申请的时间为准。

用户直接拒收时，商城通常会自动提交退货申请；仍建议用户在物流录入拒收信息后检查订单售后状态。

## 哪些商品不适用

法律明确排除的类型包括定作商品、鲜活易腐商品、在线下载或已拆封的音像制品及计算机软件等数字商品、报纸和期刊。

下列性质的商品只有在商城或商家显著标注，并由用户购买时确认后，才可以不适用七天无理由退货：

1. 拆封后影响人身安全、生命健康或容易改变商品品质的商品。
2. 激活或试用后价值贬损较大的商品。
3. 销售时已明示的临近保质期或有瑕疵商品。

商品页存在特别约定时，应以用户购买时看到并确认的页面规则为重要判断依据，但经营者不得默认勾选或擅自扩大排除范围。

## 什么叫“商品完好”

通常应同时满足：

- 商品保持原有品质和功能。
- 主商品、随机附件和配件齐全。
- 商标、标签、序列号和防伪标识完整且未被涂改。
- 赠品及办理退货要求一并返回的物品齐全。
- 没有难以恢复的划伤、碰伤、破损、污渍等外观使用痕迹。
- 没有超出合理查验所需的激活、授权或个人数据留存。

消费者基于查验需要打开包装，或为确认品质和功能进行合理调试，只要不影响商品原有品质、功能和外观，不应仅因“已拆封”直接拒绝退货。电子电器商品如果出现难以恢复的外观痕迹，或产生不合理的激活、授权和数据使用痕迹，则可能被判定为不完好。

## 寄回前检查

1. 先提交售后申请，未经审核不要自行寄往商城仓库。
2. 对商品外观、序列号、附件、赠品和包装拍照留存。
3. 退出个人账号、清除个人数据，并按页面要求关闭设备查找功能；清除数据不代表一定满足退货条件。
4. 按审核页面显示的退回地址、物流方式和材料清单寄回。
5. 保留物流底单和签收记录。

## 运费

无理由退货的退回运费通常由用户承担。无理由退货后订单不再满足包邮条件时，商城还可以在退款中扣除原寄出商品的运费。质量原因或商城原因且符合政策的退货，不应由用户承担相应退货运费。

## 回答边界

- 不根据“拆封”“激活”一个词直接给出肯定或否定结论，应继续核对商品类别、商品页约定、使用程度和售后页面提示。
- 智慧屏、定制商品、企业购、第三方商品等可能有专门规则。
- 最终资格以订单售后审核、商品检测和入库验收结果为准。
