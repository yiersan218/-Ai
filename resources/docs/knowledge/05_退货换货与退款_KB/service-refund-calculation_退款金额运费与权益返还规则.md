# 退款金额、运费与权益返还规则

## 普通退款方式和时间

商品退款原则上按原支付方式退回。工作人员审核通过，仓库收到退回商品及要求一并寄回的发票、保修卡、检测报告、附件和赠品，并确认符合退换货标准后，商城一般在 3 至 5 个工作日内完成退款处理。

“商城完成退款”不等于资金已经到账。银行卡、第三方支付机构或银行仍可能需要额外处理时间，应分别查看售后单退款状态和原支付账户流水。

## 退款金额可能由哪些部分组成

退款结果通常以订单和售后单结算明细为准，可按以下项目理解：

`预计退回金额 = 可退商品实付金额 - 应由用户承担的运费 - 应扣回的积分或其他权益 - 暂扣的纸质发票税点等项目`

该表达仅用于解释构成，不能代替订单实际计算，也不能据此向用户承诺具体金额。

## 运费承担

| 场景 | 常见处理 |
|---|---|
| 符合三包的质量问题 | 商城或商家承担符合规则的退回运费 |
| 商城或商家错发、漏发、物流损坏等责任 | 商城或商家承担符合规则的退回运费 |
| 七天无理由、个人原因退货 | 用户承担实际退回运费 |
| 无理由退货后订单不再满足包邮条件 | 可能同时扣除原寄出商品的运费 |

寄回方式必须遵循审核页面要求；用户自行选择高附加值配送或未确认的到付方式，额外费用可能不被承担。

## 优惠券、花瓣、积分与代金券

### 优惠券和花瓣

华为商城《退款方式和周期》注明，因退货引起退款时，优惠券和花瓣不予退回。具体活动券另有规则的，以活动页面和售后单为准。

### VMALL 积分

- 购物获得的积分：退货进入相应流程后会扣回该退货商品产生的积分；账户积分不足时，不足部分可能按 100 积分折算 1 元，从退款中扣除。
- 下单时使用积分抵扣：发生退货后，退货商品分摊使用的积分会按规则返还至华为帐号。
- 使用积分抵扣的开票展示、整单或部分退货限制，应以订单类型和积分规则页面为准。

“花瓣”和“VMALL 积分”不是同一个概念，回答时不能混用。

### VMALL 代金券

以旧换新等场景发放的 VMALL 代金券遵循其专项规则。退货退款时，订单中使用的代金券通常随支付款项按原路径返还；代金券不可直接兑现。其他类型代金券或活动权益应查看对应活动规则。

## 极速退款与纸质发票

极速退款订单若开具了纸质发票，首笔退款可能暂扣发票税点金额。仓库收到纸质发票和退回商品并核验无误后，再发起税点金额的第二次退款。

非质量原因使用极速退款时，还可能扣除退货运费。因此看到退款少于实付金额时，应依次核对：退货原因、运费、纸质发票、积分扣回以及售后单中的其他结算项。

## 排查退款未到账

1. 查看售后单是“审核中”“待入库”“退款处理中”还是“退款完成”。
2. 确认退回商品、赠品、附件和纸质发票是否已被仓库签收。
3. 查看原支付方式，而不是只看华为商城账户余额。
4. 核对支付机构或银行的到账时间。
5. 极速退款开过纸质发票时，检查是否仍在等待税点二次退款。
6. 超过页面预计时间仍未到账时，准备订单号和退款流水号联系商城客服。

## 回答边界

不得在缺少订单实付、支付组合、退货原因、权益使用和运费信息时计算确定退款金额。活动券、企业购、第三方商品、分期和组合支付可能有专门规则，最终以订单售后结算明细为准。
