## SKU 口径

严格 SKU 应以唯一的 `prdId + sbomCode` 以及颜色、容量、尺寸、网络版本、套餐和可售状态为准。按照本项目架构，这些数据由 MCP 实时查询，不在静态 KB 中复制。因此：

- “可追溯 SKU 锚点”只统计文档来源 URL 已出现的默认 `prdId + sbomCode` 快照。
- 它不是华为商城全部在售 SKU 总量，也不能用于回答实时库存。
- “KB 内完整严格 SKU 数据记录”为 0，表示没有把动态 SKU 清单静态化；不是商城没有 SKU。
